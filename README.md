# 🎁 Праздничный сайт-подарок на День Рождения

Красивый, современный, интерактивный веб-сайт для поздравления с Днём Рождения!

![Превью](https://images.unsplash.com/photo-1513151233558-d860c5398176?auto=format&fit=crop&w=1200&q=80)

## ✨ Особенности и фишки

1. **Интерактивная 3D-коробка с подарком 🎁:**
   - Нажми на коробку — лента развязывается, крышка эффектно слетает с салютом из конфетти!
   - Из коробки вылетает персональный **Золотой VIP-сертификат** с правом на исполнение желаний.

2. **Праздничный торт и задувание свечей 🎂:**
   - Реалистичные мерцающие огоньки свечей.
   - Кнопка «Задуть свечи» с анимацией дыма и поздравлением от Вселенной.
   - Поддержка задувания через микрофон устройства!

3. **Личное письмо с сургучной печатью 💌:**
   - Настоящий винтажный конверт. При нажатии печать ломается, и разворачивается душевное рукописное письмо.

4. **Волшебная баночка с комплиментами ✨:**
   - Более 40 тёплых, вдохновляющих и персональных пожеланий/комплиментов, которые можно доставать нажатием кнопки.

5. **Полароид-галерея фото 📸:**
   - Эстетичные карточки воспоминаний в стиле Polaroid.
   - Возможность прямо в браузере загрузить свои фотографии.

6. **Мини-игра «Лопни шарики» 🎈:**
   - Интерактивные летающие шарики: лопай их, собирай бонусы («Любви», «Счастья», «Путешествий») и конфетти.

7. **Звуковое сопровождение 🎵:**
   - Встроенный синтезатор мелодии «Happy Birthday» (на базе Web Audio API — работает автономно, без внешних mp3 файлов!).
   - Звуковые эффекты лопания, открытия подарка, затухания свечей.

8. **Удобный персонализатор 🪄:**
   - Кнопка «Настроить» прямо на сайте позволяет легко поменять имя именинника, текст поздравлений и подпись.
   - Кнопка **«Скопировать ссылку с настройками»** формирует готовую ссылку, которую можно отправить имениннику в Telegram / WhatsApp / VK!

## 🚀 Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Jdkdkdiriej8383/PodarokNaDR.git
   cd PodarokNaDR
   ```
2. Установите зависимости и запустите:
   ```bash
   npm install
   npm start
   ```
3. Откройте в браузере: `http://localhost:3000`  
   *(Или просто дважды кликните по файлу `index.html` — сайт работает даже без сервера!)*

## ☁️ Деплой на бесплатный хостинг Render

Сайт готов к моментальному развертыванию на [Render.com](https://render.com).

### Способ 1: Бесплатный Static Site (Самый быстрый, никогда не засыпает)
1. Зарегистрируйтесь / войдите на [Render.com](https://render.com).
2. Нажмите кнопку **New +** → выберите **Static Site**.
3. Подключите ваш GitHub репозиторий `Jdkdkdiriej8383/PodarokNaDR`.
4. Укажите параметры:
   - **Name**: `podarok-na-dr` (или любое имя)
   - **Branch**: `main`
   - **Build Command**: *(оставьте пустым)*
   - **Publish Directory**: `.` (просто точка — текущая папка)
5. Нажмите **Create Static Site**.
6. Через 30 секунд ваш сайт будет доступен по бесплатному адресу вида `https://podarok-na-dr.onrender.com`!

### Способ 2: Web Service (Node.js)
1. Нажмите **New +** → выберите **Web Service**.
2. Подключите ваш репозиторий.
3. Render автоматически определит Node.js приложение:
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: `Free`
4. Нажмите **Deploy Web Service**.

## 💝 Как отправить подарок имениннику

1. Откройте ваш опубликованный сайт на Render.
2. Нажмите в правом верхнем углу **«Настроить»** (волшебная палочка).
3. Введите имя виновника торжества (например, *«Анечка»* или *«Любимый»*).
4. Нажмите **«Копировать ссылку с настройками»**.
5. Отправьте скопированную ссылку имениннику в мессенджере — когда он откроет её, всё будет персонализировано специально для него! 🎉
